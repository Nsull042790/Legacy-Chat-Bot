Legacy Mortgage Chatbot Widget

This page demonstrates the Legacy Mortgage chatbot widget. Look for the chat button in the bottom-right corner!

Installation

Add this single line to your website (before the closing </body> tag):

<script src="https://nsull042790.github.io/Legacy-Chat-Bot/widget.js"></script>

Configuration (Optional)

Customize the widget by adding this before the script tag:

<script>
window.LMCConfig = {
  autoOpen: true,        // Auto-open on page load
  autoOpenDelay: 2000,   // Delay in milliseconds
  autoOpenOnce: true     // Only auto-open once per session
};
</script>
Note: The widget will auto-open after 2 seconds by default. Set autoOpen: false to disable this.
